# CodexPhone v0.2.1 · Android + Windows Preview

本次小版本同步改进原生安卓、Web 和 Windows 启动面板。

- **Mermaid**：Web 与安卓本地渲染完整图表，支持放大和源码查看；不依赖 CDN，语法错误保留源码。
- **最新优先**：进入对话只获取最近 20 轮，默认定位最新；历史内容按需分页加载，减少长对话首屏等待。
- **对话导航**：按钮打开轮次摘要，可跳到某轮、加载更早内容或回到最新消息。
- **排队与引导**：运行中发送默认排队，输入框上方展示待发条；本轮结束后自动续发，点击右侧“引导”插入当前轮次。
- **Windows 面板**：中文自然语言状态、独立连接信息卡片、活跃任务/配对设备数量、折叠诊断日志；任务运行时说明为什么暂不能升级桥接。

排队内容持久保存在电脑，手机离线仍会续发。提交结果不确定时停止自动重发，检查对话后再移除记录；移除不会取消可能已执行的消息。两端继续共用原有 Codex 后端与 API 配置。本版继续维护 Web，后续优先安卓体验。

## 安装升级

Android 8.0+ 安装本页的签名 Release APK，v0.2.0 正式 APK 可直接覆盖安装。Windows x64 使用同版本 EXE；**请等待当前任务结束后再刷新桥接，不要强行中断 Codex**。旧桥接正在运行时，打开新版 EXE 可能仍复用旧服务；空闲时点击“配对另一台手机”刷新桥接，已有授权保留。App 设置中确认 Host 为 **0.2.1** 后使用排队和最新历史分页。

手机与电脑加入同一个 Tailscale 网络，使用面板地址和一次性配对码；无需 Serve/Funnel 或官方账号。仅升级 APK 不会替换电脑 Host。

全部发布附件 SHA-256 见 SHA256SUMS.txt；安卓签名与验证信息见 android-release.json。源代码、构建脚本、许可与开发说明均在仓库。

## 验证与边界

已验证浏览器流程、隔离 Codex 协议中的队列自动续发/手动引导/最新分页，以及 API 35 模拟器上的本地图表、原生排队流程和长对话导航。测试使用本地模拟服务，不调用真实付费模型。不同手机键盘、厂商后台策略和各 API 服务仍需实际设备验证，因此 GitHub 保留 Preview 标记。

本版不提供锁屏推送、图片上传或多电脑同时连接。桌面共享仍依赖 Codex 当前启动入口和实验性 WebSocket 传输。Windows EXE 尚未代码签名；APK 使用与上一版一致的发布密钥签名。Codex / Tailscale 不随包分发。本项目采用 MIT，非 OpenAI 官方产品。
