# CodexPhone 0.3.1 Preview

修复 Windows 管理中心启动共享连接后，其他功能一直变灰无法使用的问题。共享启动和等待 Codex 正常退出现在在后台进行；管理中心保持可操作，状态会解释当前等待步骤。改进按钮的主次层级、禁用状态和标签页样式。

Android 登录页记住最近成功连接的账号服务器和用户名，可以在多台自建账号服务之间切换；密码不保存。新增清晰的“退出登录”操作，退出时撤销手机会话并清除本机对话数据，保留已记住的服务器，方便下次登录。

升级时先等待现有 Codex 任务结束，再运行 Windows 安装包并安装 APK。桌面共享操作可在后台等待 Codex 安全退出，无需一直锁住管理中心。APK 保持原发布密钥，可直接覆盖 0.3.0。

本版仍为 Preview。默认账号服务端口 4321，桥接端口 4318，均应限制在可信内网/Tailscale。
