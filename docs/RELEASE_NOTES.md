# CodexPhone 0.3.5 Preview

- 桌面“开始连接手机”同时检查账号服务和共享连接。概览页分别展示账号服务、Tailscale 与电脑连接状态，并提供可复制的手机登录地址。
- 概览页增加“创建账号 / 绑定电脑”入口，绑定成功自动返回概览；重新打开管理中心会恢复已绑定的服务地址与电脑信息。
- 安卓登录页明确说明账号服务默认使用 4321，任务连接使用 4318。登录接口返回 404 时，直接显示端口排查指引。
- 安卓增加全部、运行中、收藏筛选；Web 同步增加运行中筛选。空页面区分搜索、项目与连接情况，筛选无匹配项时仍可继续分页。
- 安卓排队消息默认折叠为数量摘要，展开后仍可引导或移除；无可启动项目时在发送前给出登记路径。待确认提交用自然语言解释，可查询、查看对话或用原编号安全重试。
- 桌面等待 Codex 正常退出时保留启动提示，周期刷新不会覆盖；调整按钮悬停对比与标签页文字继承，更新界面截图和操作说明。

三个体验改造阶段整合为一次 0.3.5 升级。APK 使用原发布签名与 versionCode 305，可覆盖安装 0.3.4。Windows 切换共享桥接仍需等待当前任务结束，本次构建不自动替换运行中的桥接。

# CodexPhone 0.3.4 Preview

放宽自建账号创建条件：用户名支持中文、字母和数字，长度 2–64 位；密码至少 6 位，不要求大小写或数字组合。

点击启动账号服务时会检测并自动更新旧版常驻服务；重启只涉及账号接口，SQLite 账号、绑定和登录记录会保留。无需手动找进程或重启电脑。

保留 0.3.1/0.3.2 中的后台共享启动、设备管理界面、Android 服务器记忆、服务器切换和退出登录功能。APK 使用原发布密钥及更高 versionCode，可覆盖安装 0.3.3。账号服务建议仅通过可信的 Tailscale 私网访问。

本版仍为 Preview。默认账号服务端口 4321，桥接端口 4318，均应限制在可信内网/Tailscale。
