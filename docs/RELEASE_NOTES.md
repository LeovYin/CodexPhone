# CodexPhone v0.1.2

首个 Windows x64 预览版本，使用 MIT 许可证。

v0.1.2 修复源码版与 EXE 版、不同安装目录间的桥接误判：核对命令行、程序清单、后端归属与健康状态后复用共享服务，保留正在运行的任务。仍会拒绝未知端口占用者。新增多尺寸应用图标、手机网页图标、README 横幅和桌面快捷方式入口。

v0.1.1 修正云端 Windows 构建环境缺少 Get-FileHash 时的校验兼容性，改为直接使用 .NET SHA-256；保留 v0.1.0 发布记录。

- 单文件 EXE，自带 Node.js 和原生适配器，释放至当前用户目录。
- 原生启动面板：启动共享连接、换发配对码、环境检查、查看日志。
- 手机与原版 Codex 共用后端，支持继续已有对话、任务事件、审批和中断。
- Enter 换行，Markdown/GFM、鉴权本地图片、安全 SVG 预览。
- 动态模型与思考强度、手机布局、项目管理、重点对话。
- 自动发现本机 Tailscale 地址，无需 Tailscale Serve。
- 包含 SHA-256 校验文件和第三方许可声明，不包含个人配置或聊天历史。

要求：Windows 11 x64、已配置可用的 Codex Windows 桌面应用、自己的 Tailscale 网络。

当前已验证 Codex 26.1023.6123.0 / CLI 0.165.0-alpha.1.2。未测试版本、真实手机软键盘和各 API 服务模型支持需要在对应环境确认。

这是社区工具，不是 OpenAI 官方客户端。此预览 EXE 未进行代码签名。使用前阅读使用说明；请勿将手机桥接端口直接暴露到公网。
