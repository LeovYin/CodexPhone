# CodexPhone 0.3.0 Preview

本版优先修复 Agent 提问无法在手机回答、导致任务等待的问题。Android 与 Web 会在任务列表或对话中显示全局问答弹窗，支持选择、文字、多问题校验和机密字段；答案按原始问题 ID 回传。桥接初始化时保留重放请求，重新连接也可恢复正在等待的提问。已通过真实 CLI + 本地模型模拟服务验证“桌面提问 → 手机回答 → Agent 继续”，未调用外部模型 API。

新增独立自建账号服务，使用随包 Node 内置 SQLite，无需安装数据库。一个账号绑定一台电脑，手机登录后找到电脑。首次填写自己的账号服务地址，登录保持 30 天；不依赖 Codex 官方账号。Windows 改为 WPF 连接管理中心，可管理本机手机的只读、控制和禁用权限。绑定成功后旧配对授权失效，需要手机登录账号。

Android 将对话显示缓存与草稿/未确认提交分开加密原子保存，限制缓存体积并消除重复显示 ID。异常退出后跳过显示缓存，保留登录和提交记录；设置可单独清理缓存。Mermaid WebView 渲染进程退出时隔离处理。尚未取得用户故障手机的崩溃日志，因此不能断言覆盖所有启动崩溃原因。

升级：先等任务结束。在新版管理中心“诊断与帮助”选择“更新共享服务”，确认实际 Host 为 0.3.0，然后在账号页创建账号并绑定。默认桥接 4318、账号服务 4321，均通过自己的 Tailscale 网络访问。升级安装 APK 不会自动替换仍在运行的旧桥接。本次发布不会主动重启用户的服务。

Windows EXE 尚未代码签名；Android Release APK 延续已有发布密钥，可覆盖安装上一版 Release。GitHub 保留 Preview 标记，仍需不同手机、WebView 与系统后台策略的实际验证。不提供锁屏推送、图片上传或多电脑同时连接。MIT 开源，非 OpenAI 官方产品。
