# CodexPhone 0.3.7 Preview

- 安卓“设置”新增“断开服务器”，立即停止手机实时连接与同步，返回可编辑地址的连接页。电脑任务与排队消息继续运行，不调用退出账号、撤销设备或中断任务接口；重新打开 App 也不会自行重连已断开的入口。
- 支持为局域网和 Tailscale 入口分别记住账号服务地址、用户名及可选的电脑任务地址。可一键使用同一服务器的 4318 端口，也可留空继续使用账号登记地址，兼容独立部署账号服务及自定义端口。
- 更换网络入口后重新登录同一账号即可连接电脑，无需在电脑管理中心反复修改全局绑定。草稿、对话缓存与未确认提交按账号及电脑分别保存；同一电脑切换入口可恢复，不同电脑不会串用待发送内容。
- “退出登录”继续用于撤销手机连接并清除当前电脑的本机对话记录，与“断开服务器”分开。登录页明确区分局域网和 Tailscale 使用方式，不再要求局域网用户启用 Tailscale。

安卓 APK 使用原发布签名与 versionCode 307，可覆盖安装 0.3.6。本功能兼容 0.3.6 电脑服务，可只更新 APK；Windows 包仅同步版本与说明，无需为了本功能中断电脑任务。更换入口需要重新输入密码，密码不会保存。首次连接每个入口时，请核对账号服务（默认 4321）与电脑任务（默认 4318）地址均能通过该网络访问。

# CodexPhone 0.3.6 Preview

- 安卓 Markdown 网页链接和正文中的 HTTP / HTTPS 地址支持点击打开浏览器。文件链接使用蓝色下划线并注明“文件 · 暂不支持打开”，点击仅作说明，不读取或打开电脑文件；代码块内的地址保持原样。
- 修复一种可能造成“电脑浏览器正常、安卓返回 502”的代理兼容问题：内网、Tailscale IP 与 `.ts.net` 地址直接连接，不经过系统 HTTP 代理；公共网站仍遵循系统代理设置。此修复不会关闭 VPN 或改变 Tailscale 路由。
- 登录、电脑授权、模型与对话读取分别标明失败阶段，区分 HTTP 状态、非 JSON 网关响应、连接超时、域名解析和证书错误。错误卡支持展开目标地址与接口，以及复制诊断信息，不包含密码、令牌或原始网关页面。
- 登录过程展示当前步骤；账号绑定了本机回环/监听地址时，明确提示在电脑管理中心修正为 Tailscale 地址。电脑向账号服务核验授权时，也能准确解释 HTML 502 和错误端口。

502 的现场根因仍需结合错误发生阶段确认；已用模拟代理复现旧版 502 并验证内网直连修复。如更新后仍有错误，请点击“复制错误信息”反馈，而不是反复发送同一消息。电脑浏览器可用不等于手机能同时访问账号服务 4321 与任务连接 4318。

APK 使用原发布签名与 versionCode 306，可覆盖安装 0.3.5 并保留登录及缓存。安卓代理兼容与链接修复可先单独更新 APK；完整的电脑账号服务诊断需在当前任务完成后更新 Windows EXE。本次构建不替换运行中的桥接。

# CodexPhone 0.3.5 Preview

- 桌面“开始连接手机”同时检查账号服务和共享连接。概览页分别展示账号服务、Tailscale 与电脑连接状态，并提供可复制的手机登录地址。
- 概览页增加“创建账号 / 绑定电脑”入口，绑定成功自动返回概览；重新打开管理中心会恢复已绑定的服务地址与电脑信息。
- 安卓登录页明确说明账号服务默认使用 4321，任务连接使用 4318。登录接口返回 404 时，直接显示端口排查指引。
- 安卓增加全部、运行中、收藏筛选；Web 同步增加运行中筛选。空页面区分搜索、项目与连接情况，筛选无匹配项时仍可继续分页。
- 安卓排队消息默认折叠为数量摘要，展开后仍可引导或移除；无可启动项目时在发送前给出登记路径。待确认提交用自然语言解释，可查询、查看对话或用原编号安全重试。
- 桌面等待 Codex 正常退出时保留启动提示，周期刷新不会覆盖；调整按钮悬停对比与标签页文字继承，更新界面截图和操作说明。

三个体验改造阶段整合为一次 0.3.5 升级。APK 使用原发布签名与 versionCode 305，可覆盖安装 0.3.4。Windows 切换共享桥接仍需等待当前任务结束，本次构建不自动替换运行中的桥接。

# CodexPhone 0.3.4 Preview

放宽自建账号创建条件：用户名支持中文、字母和数字，长度 2–64 位；密码至少 6 位，不要求大小写或数字组合。

点击启动账号服务时会检测并自动更新旧版常驻服务；重启只涉及账号接口，SQLite 账号、绑定和登录记录会保留。无需手动找进程或重启电脑。

保留 0.3.1/0.3.2 中的后台共享启动、设备管理界面、Android 服务器记忆、服务器切换和退出登录功能。APK 使用原发布密钥及更高 versionCode，可覆盖安装 0.3.3。账号服务建议仅通过可信的 Tailscale 私网访问。

本版仍为 Preview。默认账号服务端口 4321，桥接端口 4318，均应限制在可信内网/Tailscale。
