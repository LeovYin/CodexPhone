# CodexPhone 使用说明

CodexPhone 是社区开源工具，让手机通过自己的 Tailscale 网络继续电脑上的 Codex 对话。它不是 OpenAI 官方产品。

## 使用前准备

- Windows 11 x64，已安装 Codex Windows 桌面应用。
- 先确认电脑里的 Codex 能正常发消息；使用自己的 API 服务或已有的 Codex 配置。
- 电脑和手机安装 Tailscale，并登录同一网络；不需要启用 Serve 或 Funnel。
- 本版本不支持 macOS、Linux 或 Windows ARM64。

EXE 已包含 Node.js 和本项目原生适配器，不需要另外安装 Node.js、pnpm 或编译器。Codex 和 Tailscale 需要分别自行安装。

## 第一次连接

1. 下载并打开 CodexPhone EXE。它会把程序释放到当前用户的 LocalAppData/CodexPhone/versions，不需要管理员权限。
2. 点击“开始连接手机”。程序会检查或启动账号服务及共享连接。如果电脑 Codex 尚未使用共享模式，请完成当前任务后，从 Codex 菜单正常退出；本程序会自动重新打开它。
3. 等待操作完成。为覆盖 Codex 启动时的配置刷新，程序会等待后端稳定至少 15 秒。
4. 在管理中心“账号与电脑”页创建账号（用户名 2–64 位，密码至少 6 位），或登录已有账号，然后绑定本机。
5. 在“连接概览”复制手机登录地址（默认 `http://100.x.x.x:4321`），粘贴到安卓登录页并登录相同账号。4321 是账号登录端口，4318 用于电脑任务与 Web 客户端。不要使用 `0.0.0.0` 或 `127.0.0.1` 作为手机地址。
6. 登录成功后会自动连接已绑定的电脑。电脑管理中心可打开 Web 客户端，点击“管理项目”登记目录；回到安卓刷新后，打开已有对话或点击 + 新建任务。

首次运行时 Windows 可能提示程序没有数字签名。本项目目前未签名，请核对来源和发布页 SHA-256；如果组织策略阻止运行，请联系管理员。程序不会修改安全策略。

## 日常使用

- 以后使用 CodexPhone 的“开始连接手机”打开 Codex。直接从开始菜单打开，可能使用独立后端。
- 按回车换行，点击箭头发送。模型和思考强度由本机 Codex 的目录提供，实际可用性取决于自己的服务。
- Web 和 Android 默认打开最新消息，首屏只获取最近 20 轮；“对话导航”可查看摘要、跳转轮次或回到最新，“加载更早消息”按需读取历史。
- 完整的 Mermaid 代码块会本地绘图，可放大和查看源码；语法错误时保留源码供检查。
- 运行中点击发送会排队，显示在输入框上方；本轮结束后电脑自动续发。点击排队条右侧“引导”可插入当前轮次，干预正在执行的任务。
- Codex 请求你补充信息时，手机会显示全局回答窗口。所有问题都填写后提交，电脑上的 Agent 收到答案后继续工作。也可以稍后回答，在待处理中恢复。
- 排队内容保存在电脑，手机离线仍会续发。显示“结果待确认”时先核对对话；移除记录不取消可能已执行的消息。不要重复发送同一条未确认内容。
- 手机和电脑共享同一后端；在同一个对话中接着发消息即可。
- 管理手机权限：打开“手机与权限”，分别设为只读、可控制或撤销/禁用。禁用会断开此手机，并阻止它通过重新登录获取本机访问权限。
- 关闭启动面板不会停止正在运行的 Codex 或手机桥接。
- 管理中心分别显示账号服务、Tailscale 与电脑共享连接状态，概览页可复制手机登录地址。“诊断与帮助”保留原始日志。任务运行时拒绝替换桥接属于保护机制，请等待任务结束。
- 源码版或另一版本已在共享时，新版会核对归属后直接复用，避免中断任务。若要完整切换运行文件，先完成任务、正常退出 Codex 再启动新版；不要在旧服务仍使用文件时删除旧目录。
- 点击面板右下方“桌面快捷方式”，程序会在用户目录保存一份稳定的 EXE 并创建桌面入口。下载文件移动后，快捷方式仍可用。
- API 配置和聊天历史保留在 Codex 自己的用户目录。账号 SQLite、设备授权、重点对话和项目登记保存在 `%USERPROFILE%/.codexphone/`。备份时将 `accounts` 目录视作含账号数据的敏感文件。
- 手机浏览器没有安装要求；HTTP 地址下不保证“安装到桌面”或 Service Worker 等需要安全上下文的功能。

## 手机打不开或发送失败

1. 确认两端 Tailscale 在线，手机使用面板显示的本机地址，而不是别人的 IP。
2. 点击“检查环境”，检查 Codex、共享桥接和依赖状态。
3. 查看防火墙或 Tailscale ACL 是否允许自己的手机访问电脑 TCP 4321（账号服务）和 4318（任务）。登录显示没有接口或 404 时，先确认地址是否误填成了 4318。程序不会自动创建防火墙规则。
4. 若桥接显示 disconnected/degraded，等待电脑 Codex 完成启动并恢复连接。
5. 若 4318 被其他程序占用，不要随意结束未知程序；可从 PowerShell 使用 scripts/Start-SharedCodex.ps1 -PhonePort 其他端口启动。
6. 日志目录可从面板打开。求助时只提交经过检查的必要片段；日志可能含配对码或项目名称，不要上传整个用户目录。

安卓 0.3.6 起，错误卡会区分账号登录、电脑授权、模型和对话读取阶段，可展开目标地址、HTTP 状态和接口并复制。502 若标为“非 JSON 响应”，应重点检查错误端口、HTTP 代理或反向代理。App 已让内网与 Tailscale 请求绕过系统 HTTP 代理；其他 VPN 或透明代理的路由仍需在对应软件中检查。发送结果未确认时先查询状态，不要另发相同内容。

安卓对话中的网页链接可直接打开浏览器。文件链接会显示“文件 · 暂不支持打开”，点击仅提示当前边界，不读取电脑文件。

## 更新与移除

- 更新前先完成任务并正常退出 Codex，再运行新版本 EXE。配对数据在用户目录中，升级不清空。
- 切换版本时不要让新旧两个启动面板同时操作服务。
- 原始 Codex App Server 仅监听 127.0.0.1；手机连接的是带鉴权的桥接端口。
- 恢复独立模式：先完成任务并退出 Codex，运行释放目录里的 Restore-Standalone.cmd。之后手机和电脑拥有独立后端，不能同时控制桌面持有的对话。
- 移除：退出 Codex 后，结束已核对属于本程序的手机桥接，再删除 LocalAppData/CodexPhone 下的程序文件。用户目录 .codexphone 是配对数据，按需保留。
